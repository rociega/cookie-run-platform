# X thread — Cookie Run demo

## Post 1

Meet Cookie Run: a secure, ephemeral GPU workspace for developers.

Spin up a machine for a build, model run, preview, migration, or experiment. Connect over SSH, do the work, and let the workspace disappear when the session ends.

No long-running server to maintain. No idle GPU sitting unused.

## Post 2

Using Cookie Run is simple:

1. Choose a machine from the catalog.
2. Select the region, image, and session duration.
3. Connect your wallet.
4. Review the live quote and confirm payment.
5. Connect over SSH when the workspace is ready.

The rental flow stays visible from quote to teardown.

## Post 3

Cookie Run uses native COOK on Cookie Chain as its default payment path.

That means the payment is native to the network, the quote is visible before checkout, and the server verifies the transaction before provisioning the machine.

Cookie Chain keeps the rental flow fast, transparent, and purpose-built for the app.

## Post 4

Need mainnet settlement instead?

Solana mainnet SOL is available as a separate premium route. Cookie Chain COOK and Solana SOL are verified against their own networks and RPCs so a payment cannot be confused with another chain.

## Post 5

Cookie Run is designed around short-lived access:

- Wallet challenges expire.
- Private source credentials are never stored with a rental.
- SSH access appears only after provisioning.
- Access ends when the lease ends.

Temporary machines should have temporary access.
